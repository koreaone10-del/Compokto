# AXIOM

واجهة محادثة/وكيل واحدة، متوافقة مع أي API بصيغة OpenAI، تعمل على الهاتف بلا تركيب.

## المزايا
- أوضاع: عام / برمجة / تحليل / تهكير / كتابة
- رفع صور وملفات نصية وكود
- نسخ الردود ومقاطع الكود بضغطة
- أدوات: Base64، Hex، URL، SHA-256، JWT، جلب صفحات
- المفتاح يبقى في متصفحك فقط

## التشغيل
1. ارفع المجلد إلى مستودع GitHub جديد.
2. Vercel ← Add New Project ← استورد المستودع ← Deploy (بلا متغيرات بيئة).
3. افتح الرابط ← الإعدادات ← ضع Base URL والمفتاح والموديل.

## مزوّدون
| المزوّد | Base URL |
|---|---|
| Venice | `https://api.venice.ai/api/v1` |
| OpenRouter | `https://openrouter.ai/api/v1` |
| Groq | `https://api.groq.com/openai/v1` |
| Ollama محلي | رابط النفق + `/v1` |

## تنبيه
`maxDuration` على Vercel Hobby محدود؛ الردود الطويلة جداً قد تُقطع. للاستخدام الثقيل استخدم خطة Pro أو مزوّداً سريعاً.
